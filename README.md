# E-Commerce Backend Platform

Backend-focused e-commerce application built using Spring Boot, JWT authentication, MySQL, Docker, Swagger, and Spring Data JPA.

## Features
- JWT-based Authentication & Authorization
- Role-Based Access Control (RBAC)
- Product, Cart, User, and Order Management
- RESTful APIs using Spring Boot
- Dockerized Deployment
- Optimized API Performance
- Modular and Scalable Backend Architecture

## Tech Stack
- Java 8
- Spring Boot
- Spring Security
- Spring Data JPA
- MySQL
- Docker
- Swagger
- Maven
